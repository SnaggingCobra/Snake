# Snake Game

A simple Snake game made with HTML, CSS, and JavaScript.

## Features

- Eat apples to score points; the snake speeds up as you play.
- Avoid temporary bombs that shorten the snake.
- High scores are saved in your browser.
- Custom game artwork and a replay option.

## Play

Open `index.html` in a browser and use the arrow keys to move. Hitting a wall or yourself ends the game.
